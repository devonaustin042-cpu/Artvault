# ArtVault

## Deskripsi Project

ArtVault adalah sebuah website yang dibuat untuk menampilkan berbagai karya siswa dan siswi sekolah dalam bentuk digital. Website ini bertujuan untuk menjadi wadah apresiasi kreativitas siswa sekaligus mempermudah guru, siswa, dan pengunjung dalam melihat hasil karya yang telah dibuat.

Melalui website ini, pengguna dapat melihat berbagai kategori karya seperti desain, fotografi, lukisan, poster, video, dan karya kreatif lainnya dengan tampilan yang sederhana, modern, dan mudah digunakan.

---

## Tujuan Pembuatan

* Menampilkan hasil karya siswa secara online.
* Meningkatkan apresiasi terhadap kreativitas siswa.
* Mempermudah dokumentasi karya sekolah.
* Menjadi media informasi dan promosi kegiatan sekolah.

---

## Fitur Website

* Halaman utama (Homepage)
* Gallery karya siswa
* Detail karya
* Navigasi yang responsif
* Tampilan modern dan user friendly
* Responsive untuk desktop dan mobile

## Cara Menjalankan Project

1. Download atau clone repository ini.
2. Buka folder project.
3. Jalankan file `index.html` di browser.

Atau jika menggunakan framework:

```bash
npm install
npm run dev
```
